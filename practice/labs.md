# Лабораторні роботи

## Лабораторна робота №1

### Тема

Дослідження алгоритму Bubble Sort.

### Мета

Навчитися реалізовувати алгоритм Bubble Sort та аналізувати його складність.

### Хід роботи

1. Створити масив випадкових чисел.
2. Реалізувати Bubble Sort.
3. Вивести результат сортування.
4. Порахувати кількість обмінів.
