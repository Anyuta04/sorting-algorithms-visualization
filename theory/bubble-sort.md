# Bubble Sort

## Що таке Bubble Sort

Bubble Sort — це простий алгоритм сортування, який працює шляхом багаторазового порівняння сусідніх елементів масиву та їх обміну місцями.

Алгоритм поступово переміщує найбільші елементи в кінець масиву.

---

## Принцип роботи

1. Порівнюються два сусідні елементи.
2. Якщо лівий елемент більший — вони міняються місцями.
3. Прохід повторюється для всього масиву.
4. Після кожного проходу найбільший елемент опиняється в кінці.

---

## Складність алгоритму

- Найгірший випадок: O(n²)
- Середній випадок: O(n²)
- Найкращий випадок: O(n)

---

## Переваги

- Простий для розуміння
- Легко реалізується
- Добре підходить для навчання

---

## Недоліки

- Повільний на великих масивах
- Неефективний для складних задач

---

## Приклад на Python

```python
def bubble_sort(arr):

    n = len(arr)

    for i in range(n):

        for j in range(0, n - i - 1):

            if arr[j] > arr[j + 1]:

                arr[j], arr[j + 1] = arr[j + 1], arr[j]

arr = [5, 2, 8, 1]

bubble_sort(arr)

print(arr)
```

## Приклад на JavaScript

```javascript
function bubbleSort(arr){

    for(let i = 0; i < arr.length; i++){

        for(let j = 0; j < arr.length - i - 1; j++){

            if(arr[j] > arr[j + 1]){

                let temp = arr[j];

                arr[j] = arr[j + 1];

                arr[j + 1] = temp;
            }
        }
    }

    return arr;
}
```
