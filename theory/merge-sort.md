# Merge Sort

## Що таке Merge Sort

Merge Sort — це ефективний алгоритм сортування, який використовує принцип «розділяй і володарюй».

Масив багаторазово ділиться на менші частини, після чого ці частини об’єднуються у правильному порядку.

---

## Принцип роботи

1. Масив ділиться на дві частини.
2. Кожна частина знову ділиться навпіл.
3. Поділ триває, доки не залишаться окремі елементи.
4. Частини поступово об’єднуються у відсортованому порядку.

---

## Складність алгоритму

- Найгірший випадок: O(n log n)
- Середній випадок: O(n log n)
- Найкращий випадок: O(n log n)

---

## Переваги

- Ефективний для великих масивів
- Має стабільну складність
- Добре демонструє рекурсію

---

## Недоліки

- Складніший для розуміння
- Потребує додаткової пам’яті

---

## Приклад на Python

```python
def merge_sort(arr):
    if len(arr) > 1:
        mid = len(arr) // 2

        left = arr[:mid]
        right = arr[mid:]

        merge_sort(left)
        merge_sort(right)

        i = j = k = 0

        while i < len(left) and j < len(right):
            if left[i] < right[j]:
                arr[k] = left[i]
                i += 1
            else:
                arr[k] = right[j]
                j += 1

            k += 1

        while i < len(left):
            arr[k] = left[i]
            i += 1
            k += 1

        while j < len(right):
            arr[k] = right[j]
            j += 1
            k += 1

    return arr
```
