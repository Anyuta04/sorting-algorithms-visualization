# Глосарій

## Алгоритм

Чітка послідовність дій для розв’язання певної задачі.

## Сортування

Процес упорядкування елементів за певною ознакою.

## Масив

Структура даних, яка зберігає набір елементів одного типу.

## Ітерація

Один крок повторення циклу.

## Складність алгоритму

Оцінка кількості ресурсів, які потрібні алгоритму для виконання.

## Big O

Позначення, яке використовується для опису швидкості зростання складності алгоритму.

## Рекурсія

Спосіб розв’язання задачі, коли функція викликає саму себе.
