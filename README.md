# Візуалізація алгоритмів сортування

## Опис проєкту

Навчальний веб-проєкт для учнів 10–11 класів, присвячений вивченню алгоритмів сортування через інтерактивні візуалізації та практичні завдання.

---

## Мета проєкту

Сформувати розуміння принципів роботи алгоритмів сортування через сучасні цифрові технології та інтерактивне навчання.

---

## Алгоритми

- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
