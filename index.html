Візуалізація Bubble Sort

Теоретичний матеріал

Bubble Sort

Bubble Sort порівнює сусідні елементи та міняє їх місцями, якщо вони розташовані неправильно.

Selection Sort

Selection Sort знаходить найменший елемент і переносить його на початок невідсортованої частини.

Insertion Sort

Insertion Sort поступово вставляє кожен елемент у правильну позицію.

Merge Sort

Merge Sort ділить масив на частини, а потім об’єднує їх у відсортованому порядку.
